# Changelog

All notable changes to this project will be documented in this file.

## Version 1.0.0 (Current)

### Initial Release

### Added

#### Face Tracking
- Integrated MediaPipe Face Mesh
- Real-time facial landmark detection
- Nose landmark tracking
- Face loss detection

#### Head Tracking
- Cursor control using nose movement
- Manual calibration
- Adaptive sensitivity
- Adaptive cursor smoothing
- Dead zone filtering

#### Eye Tracking
- Eye Aspect Ratio (EAR) calculation
- Automatic blink calibration
- Blink threshold estimation

#### Gesture Recognition
- Left Wink detection
- Right Wink detection
- Double Blink detection
- Long Blink detection

#### Mouse Control
- Cursor movement
- Left Click
- Right Click
- Cursor Lock
- Scroll Mode

#### Smart Scrolling
- Adaptive scrolling speed
- Scroll pause when eyes are closed
- Scroll dead zone
- Adjustable scroll sensitivity

#### User Interface
- Live EAR display
- Blink threshold display
- Cursor coordinates
- Nose coordinates
- Current interaction mode
- Gesture notifications
- Face lost warning
- FPS counter
- Calibration assistant

#### Safety Features
- Safe Mode
- Real Mouse Mode
- Cursor boundary protection
